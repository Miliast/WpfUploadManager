5. Verify results before marking complete. Spot-check Haiku output. Escalate only if needed.

TOKEN & CODE ECONOMY:
- PONYTAIL: Minimum code. Reuse existing methods + .NET 10 stdlib. Never cut validation/error handling/security.
- CAVEMAN TEXT (chat only): Drop filler/articles. Compact bullets. Code and identifiers stay 100% exact.
- Completeness > length limits on facts/findings. Never truncate critical lists or steps.

Handoff format to subagents must include:
- Exact files/scope
- Input context (compact)
- Expected output format
- Done criteria
